# Excogitare Roadmap

## Current Goal

Create a stable, intuitive and usable first public version of Excogitare.

The current focus is deliberately narrow:

- Stabilize the existing mindmap editor
- Fix bugs
- Improve usability where necessary
- Add PDF export
- Prepare a beta version
- Gather feedback from real users

Major new features are intentionally postponed until beta feedback is available.

## Beta

The beta phase should answer:

- Do users understand the workflow?
- Which functions are actually used?
- Where do users get stuck?
- What is missing for everyday use?
- Is the concept interesting enough to continue developing?

## Idea Pool

Future ideas are collected, but are not automatically part of the current development scope.

Examples:

- Engineering Knowledge Workspace
- Knowledge navigation
- Engineering objects
- Requirements
- Risks
- Decisions
- Measurements
- Versioning
- Plugins
- AI assistance
- External integrations
